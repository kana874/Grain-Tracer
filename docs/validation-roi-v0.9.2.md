# GrainTracer v0.9.2-alpha — Validation用「未使用領域の可視化・自動推薦」

対象: `validation` ブランチ。Project Format v4、解析アルゴリズムv18を維持。

## 操作

1. BMPと対応するプロジェクトを読み込む。
2. 右パネル「Validation ROIの作成」で「未使用の検証候補を推薦」を押す。あるいは「手動で検証領域を指定」を押すと利用状況の表示と推薦が自動で有効になる。
3. **画像全体を示す小さな利用状況マップ**と、中央画像上の色分けが表示される。
4. **緑の点線**が、保存された学習・評価履歴に重ならない推薦位置。「緑枠の推薦範囲で作成開始」でROIが即時作成され、編集画面に進む。
5. それ以外の場所を選ぶ場合は、既存領域に触れない範囲を画像上でドラッグする。
6. 「抽出候補を下書きに取り込む」で正解線の下書きを作り、目視で正解・誤検出・欠落を修正する。全粒界の確認にチェックを入れ、「確認完了 → Validation登録」を押す。途中中断・再開可能。

## 色分け

| 色 | 位置情報の由来 | 扱い |
|---|---|---|
| オレンジ | 過去のA/B選好で評価したROI | Validationには再利用しない |
| ピンク | 部分評価・手動補正を行った位置またはROI | Validationには再利用しない |
| 青 | 既存の完全評価ROI（Training/Validation/Test/未確認） | 新規ROIを重ねない |
| 灰 | 画像の除外領域 | 推薦しない |
| 緑点線 | 保存履歴に基づいて未使用と推定できる推薦位置 | ユーザーが選択・確認する |

画面の利用状況マップは、元画像のプレビューと同じ座標系で描かれる。マウス操作は妨げない。

## 推薦アルゴリズム

- 保存済みのROI矩形をカテゴリ別に統合し、画像の範囲内にクリップ。
- 大きさ **256 / 192 / 128 / 96px** の順で、完全に未使用の正方形領域を探索。
- 各候補は重なりゼロ（既存ROI、AB投票ROI、手動評価、除外領域）を条件とする。
- 残っている領域から、過去の評価場所と距離があり、画像端から少し離れた候補を優先。
- 候補がない場合は「96px以上の安全な未使用領域は見つからない」と表示し、無理に検証ROIを自動生成しない。
- 推薦後も既存の`validationRoiConflicts`で再検査し、Validation完成時には別途、手動確認・最低20正解画素・独立性を検査する。

## 信頼性と注意

過去のプロジェクトファイルに保存されている履歴しか描けない。**色が付いていない場所を「本当に一度も学習に使っていない」と保証する機能ではない**。既に評価済みだが過去の履歴が失われた位置がある場合は、新しい未使用画像の利用や履歴の確認が必要。

緑の推薦は地理的位置の候補に過ぎず、粒界の鮮明さ・難易度・画像全体の代表性を自動保証しない。最終Validationとして適しているかは実画像を確認し判断する。

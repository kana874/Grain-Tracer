# GrainTracer v0.9.1-alpha：Validation ROI作成とA/B手動補正UI改修

更新日：2026-10-14。対象：`validation`ブランチ。
Project Format v4、画像解析アルゴリズム`boundary-v18-reflected-edge-v1`は変更なし。

## 1. Validation ROI作成ウィザード

既存の完全評価ROIを手動で`Validation`へ切り替える方式から、専用の作成フローを追加。

1. 右側の **Validation ROIの作成 → 新しい検証領域を指定**、またはA/Bダイアログ左側の **Validation ROIを新規作成** を押す。
2. A/Bダイアログから入った場合は自動で閉じ、メイン画像上で矩形をドラッグして選ぶ。
3. 選択時点は`evaluationRole:"validation"`、`verified:false`。この状態ではPrecision/Recall/F1の**独立Validation判定に使われない**。
4. 右側の **抽出候補を下書きに取り込む** で、現在の特徴量キャッシュを利用して指定ROIだけ粒界候補を抽出し、黄色い正解線の**下書き**としてインポート。インポートはマスク履歴1件でUndoできる。既存の明示的な非粒界注釈や除外領域には上書きしない。
5. メイン画像の **お手本線**、**非粒界線**、**線消去** を使って全粒界を目視確認・修正する。Validation編集モードではROI外に線を描けず、領域外へ出たドラッグは分断する。中ボタン移動・ズームは既存操作のまま。
6. **領域内の全粒界・誤検出・欠落を目視で確認した** にチェックを入れて、**確認完了 → Validation登録** を押す。少なくとも20pxの正解線、過去の学習領域と重複しないこと、ユーザーの完了宣言の3条件が必要。`verified:true`、`completedByUser:true`、確認日時・正解線数を保存する。
7. 完了前の **一時中断** または範囲指定の **中止** は`verified:false`のまま。次回 **未完了の領域を再開** を押して再開可能。既存プロジェクトに保存・復元される。
8. ValidationやTestの画像ロールからは新しい独立Validation作成フローに入らない。Training/Development画像で実施する。

### 学習データ混入の防止

- 新しいValidation ROIは、既存完全評価ROI、過去のA/B選好のROI、部分ラベル作成履歴（Positive/Negative/Missing）に**1pxでも重なると拒否**。異なる未学習範囲を選択する。
- 確認済みValidation ROIとTest ROIはA/B学習のROI推薦・候補選択から除外される。
- `guardedAdoptLocalPreference`で採用前の2候補を検証する際、Validation/Test領域に描いた手動Negativeマスクが検証時の抽出線を抑制しないよう、抽出へのNegative入力を除外する。採用後の全体マスクは通常の最新設定で再生成する。
- 既存の「完全評価ROI」で作ったTraining矩形を、未確認のままValidationに再割当する操作を禁止。既存プロジェクトに保存済みのValidationデータは互換維持。

### 限界

ユーザーの「全粒界を確認した」チェックは**人手による完了宣言**であり、アルゴリズムが画像内の正解の完全性を証明するものではない。下書き候補をそのまま確定すると誤検出・検出漏れが検証結果に混入する。必ず全範囲を確認・修正すること。
過去にTrainingに利用済みの画像位置の履歴が保存されていなかったケースは、位置の完全性まで自動証明できない。独立した新規領域を選ぶ必要がある。

## 2. A/B画面の③を横並びに変更

- 「③ 手動補正」見出しの右側に **Aを修正／Bを修正、判定（正解・誤検出・検出漏れ）、一筆なぞり切替、対象画素数（クリック時のみ）、Undo/Redo・履歴数** をコンパクトな横方向ツールバーとして配置。
- 操作説明と現在の結果は短い1行のステータスに統合。狭いウィンドウでは必要な範囲だけ折り返す。
- 一筆なぞり有効時は使わない「クリック1回の対象画素数」欄を非表示にする。
- 既存のホイールズーム、中ドラッグパン、A/B同期、Undo/Redoを維持。

## 3. テスト

- `tests/validation-roi.test.js`：領域重複、Training/A-B/手動ラベルの混入防止、未確認状態の拒否、最小正解線数、完了宣言、UI/イベント接続を検証。
- 従来の`npm test`全スイートを維持。
- Chrome/Edgeでの実BMP操作、ROI下書きインポート速度・精度はまだ実測確認していない。

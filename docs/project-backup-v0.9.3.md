# GrainTracer v0.9.3-alpha — 保存エラー対策とバックアップからの新規学習

対象: `validation` ブランチ、Project Format v4、アルゴリズム boundary-v18-reflected-edge-v1。2026-10-14。

## 修正原因

- これまでの「保存」は`src/project.js::downloadProject()`の`JSON.stringify(project, null, 2)`で完全プロジェクトを1つのJS文字列にしていました。
- 旧Auto Tune/Topology/履歴の項目が蓄積すると、JavaScriptエンジンの文字列長制限で`Invalid string length`になる可能性がありました（添付スクリーンショットと一致）。
- 診断ZIPの`src/diagnostic-serializer.js`には既にサイズ対策がありましたが、プロジェクト自体の保存経路には適用されていませんでした。バックアップ目的では学習項目を間引くべきではありません。

## 新しいファイル保存

`src/project-backup.js`で逐次JSON直列化を行い、巨大な一時文字列の生成を防止。

- 通常サイズ: `<BMP名>.graintracer.json`。Project Format v4を保持。
- 8MBを超える保存: `<BMP名>.graintracer.archive.gz`。各項目をレコード単位でストリーミング・gzip圧縮するため、巨大なJSON文字列を保持せずにバックアップを生成できる。読込時にもレコードを逐次展開する。
- 旧`.graintracer.json`だけでなく新しい`.archive.gz`も「読込」から復元可能。
- 保存する項目: 正解／非粒界／除外マスク、完全評価ROI、Validation/Test役割、フィードバック履歴、A/B投票履歴、採用監査、Classifier、ローカル較正、パラメータ、Baseline、旧最適化履歴など。自動省略はしない。
- JSONファイルの保存が成功しても、ブラウザ側のIndexedDBの容量制限等で自動保存が失敗する場合がある。その際はファイルダウンロード開始とIndexedDB失敗を別表示。
- `Invalid string length`以外のブラウザのメモリ容量・ディスク空き・ダウンロード制限の影響は残る。

## 「現在の学習をバックアップして新規学習を開始」

「プロジェクト」欄に2段階の専用ボタンを追加。

1. 第一段階：現在の完全プロジェクトをローカルファイルに出力。学習データはこの時点では変更・削除しない。ファイル名に「学習バックアップ」と日時を付ける。
2. 保存先でファイルを確認すると、第二段階「バックアップ保存を確認して初期化」を選択可能。ブラウザはダウンロード先での保存完了を確実に通知できないため、必ずユーザーによる確認と最終確認ダイアログを必要とする。
3. ユーザーが同意した場合に限って、対象BMPの指紋をキーとしたIndexedDBレコードを削除する。他のBMPのデータは消さない。
4. 元のBMPを`skipAutosave:true`で再読込。A/B投票、手動部分ラベル、正解／非粒界マスク、Validation ROI、採用履歴、解析パラメータを初期化する。
5. 自動保存がONなら、新規プロジェクトの状態をそのBMPの自動保存へ書き込む。以後は通常の自動保存を継続。
6. バックアップ作成後に新たな評価が入力された場合は初期化を中止し、再バックアップが必要。
7. 既存の自動保存処理が書込中の場合は、それが終わってから古いレコードを削除。削除と再読込の間は自動保存を抑止。

**元BMPはバックアップのJSON/GZIPに含まれない。** 元BMPとバックアップファイルの両方を保管する。バックアップの復元は同じBMPを開いて「読込」から行う。

## 回帰テスト

`tests/project-backup.test.js`：

- 逐次JSONシリアライズとProject Format v4往復、Packed Maskの一致
- NaNやUnicode等を含む特殊文字列、TypedArray/日付のJSON互換
- 大きい最適化履歴のストリーミング圧縮アーカイブと復元
- 多数の履歴レコードを含むストレス試験
- バックアップで元スナップショットを変更しない
- 初期化確認ダイアログ、対応BMPのIndexedDB削除、`skipAutosave`による自動復元回避、gzip読込UIの接続

ブラウザ実操作および実データを用いた大容量バックアップ/初期化のエンドツーエンド確認は未実施。ファイルが実際にPCに保存されたことを確認せず初期化しないこと。

# 正解データ作成モード v0.6.2-alpha

BMPを読込後「正解データ作成モード」。左の元画像プレビューから編集位置を選びます。サイズは元画像の**面積の1/8〜1/32**（1/8、1/9、…、1/32）から選択できます。幅・高さは同じ倍率で縮小し、元画像の縦横比を維持します。元画像の整数画素に丸めるため各辺に最大0.5pxの誤差があります。

画像をクリックするとその位置を中心に枠を配置し、枠内をドラッグするとつかんだ位置を保って移動します。画像端では枠全体が画像内に収まります。サイズ変更時も中心を保ちます。矢印キーで1px、Shift＋矢印で10px動かせます。X/Yの数値で微調整することも可能です。「選択範囲を開く」で元解像度の編集画面を読み込みます。プレビューの枠を動かしただけでは、編集中の範囲は変わりません。

最大33,554,432画素を元解像度で直接読み込みます。上限を超える選択では理由を表示して読込を無効にします。大きな範囲のUndo履歴はマスク約64MiBまで（最大25操作）に制限します。保存済み・旧版の任意サイズの範囲はそのまま復元し、サイズの選択を変更した時点で新しい縦横比に切り替わります。

編集画像・左のプレビューの両方でホイール拡大縮小（カーソル中心、2〜800%）、中ボタンドラッグ移動、全体表示・100%表示を利用できます。編集ツールの「移動」では左ドラッグでも移動できます。倍率メニューは100/200/400/800%です。表示の拡大縮小では元画像や正解マスクの解像度は変わりません。Ctrl+Z / Ctrl+Y / Ctrl+Shift+Zで正解編集のUndo/Redoができます。

粒界、粒内、除外、未確認への消去、閉領域の粒内塗り、粒の確認、Undo/Redo、倍率変更と注釈表示切替に対応。未確認は自動で負例にしません。塗りが漏れた場合はUndoして粒界を修正してください。編集すると状態は編集中に戻ります。

範囲は画像の指紋と座標でIndexedDBに自動保存し、保存範囲の選択から再編集できます。同じ画像の範囲は学習区分を統一します。端、未確認、除外に接する粒を不完全と判定します。確定は利用者が確認した状態であり、完全な注釈を自動保証しません。

JSON保存・読込に対応。正解ZIPには原寸image.png、boundary/interior/valid/exclusion.png、編集用annotations.json、粒IDのgrain-ids.u32、manifest.jsonを含みます。粒IDはlittle-endian uint32、行優先、0は背景。確認済み粒内の4近傍連結成分から採番します。編集履歴の座標は切り出し領域内、crop座標は元画像内です。scaleはµm/元画像px。

初版は手描きブラシと閉領域塗り。折れ線の頂点編集、線の自動接続、抽出下書きの採用は未実装です。注釈マスクが正本であり、strokesは操作記録です。線幅変更による再生成はまだ対応しません。

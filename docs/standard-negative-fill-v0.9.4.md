# GrainTracer v0.9.4-alpha — 非粒界の標準操作を「閉領域→非粒界」へ統一

対象: `validation` ブランチ。プロジェクト形式v4、粒界抽出アルゴリズム `boundary-v18-reflected-edge-v1` を維持。

## 変更内容

### 標準ツールバー

- 標準表示を **移動 → お手本線 → 線消去 → 閉領域→非粒界 → 除外矩形 → 完全評価ROI → Undo/Redo** に整理。
- 「非粒界線（詳細）」は通常画面で非表示。ヘッダー **詳細機能を表示** を使えば以前どおり利用できる。
- 詳細機能で非粒界線を選択したまま標準画面に戻った場合は、自動で「移動」に切り替え、隠れたブラシで意図せず線が書かれないようにする。
- A/B画面の「候補は誤検出」「一筆なぞり」等は変更しない。

### Validation ROI作成時の「閉領域→非粒界」

1. Validation ROIを作成し、必要なら「抽出候補を下書きに取り込む」。
2. 「お手本線」で粒界を閉じ、「線消去」で誤線を修正する。
3. 標準ツールバーの「閉領域→非粒界」を選んで粒内部をクリックする。
4. ユーザーが編集中のValidation ROIを超えて閉領域Fillが塗られるなら、**Fill実行前に拒否**する。ROI外へはみ出した結果を黙って切り詰めない。
5. Fillに成功したら「全粒界・誤検出・欠落の確認」チェックを外して未確認に戻す。人が再確認後「確認完了 → Validation登録」。
6. Undo/Redoは閉領域Fillの種点`closed-fill-add`履歴により、以前どおり1操作単位で取り消し・再適用可能。編集中のUndo/Redoも確認チェックを解除する。
7. 「画像端を閉境界として許可」は詳細設定に残す。画像端を用いたFillにも同じROI境界チェックが適用される。

### 安全性の判定

`src/validation-fill-guard.js` に、候補Region Indexのラベルと安全マスクを使って、確定前に候補領域の**すべての実際のFill画素**が編集中の矩形の内側か判定する処理を追加。

- 候補がROI外へ広がる場合は、マスク・種点・履歴・学習データを一切変更せずに拒否し、黄色いお手本線を閉じ直すよう案内。
- Fillが既に付けた別の種点と重なる場合でも、単純な差分ではなく今回の候補領域IDを判定するため、別の種点によって境界越えが隠れない。
- Validation作成以外の標準的な「閉領域→非粒界」操作は従来どおり。

### 互換性

- プロジェクトの`nonBoundary.centerline`、`nonBoundary.mask`、`nonBoundary.closedFillSeeds`の構造を変更しない。
- 旧「非粒界線」のラベルや、既存の閉領域FillのSeed、Training/Validation/Test ROIをすべて従来のまま読み込み可能。
- 既存データを再学習・削除する操作はない。

## テスト

`tests/validation-fill-guard.test.js`：

- Validation ROI内に収まる閉領域Fillを許可
- ROI外へまたがる閉領域Fillを拒否
- 不正な候補、領域Index、ROIの拒否
- プロジェクトv4の既存非粒界線・閉領域Fill・Validation ROIの往復
- 標準画面と詳細画面の表示切替、塗りつぶし実行前の安全判定、Undo/Redo履歴の接続確認

`npm test` / GitHub Actions上の全既存テストも実行。実BMPによるEdge上でのマウス操作確認は未実施。

## ユーザーの確認手順

1. Edgeで `Ctrl+F5` により更新し、右上のバージョンが`v0.9.4-alpha`になっていることを確認。
2. 通常画面では「非粒界線」が消え、「閉領域→非粒界」が表示されていることを確認。
3. Validation ROI内で黄色線の閉領域の内部をクリックし、オレンジの領域がFillされることを確認。
4. Validation ROI外まで連続する領域をクリックし、警告が出て誤塗りされないことを確認。
5. Undo/Redoで戻せることを確認。必要なら詳細機能を表示し、旧「非粒界線」を確認。

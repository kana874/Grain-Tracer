# GrainTracer 簡易フィードバック学習 v0.6.4-alpha

作成日: 2026-10-14  
対象: `validation` ブランチ  
実装範囲: 部分ラベルの高速収集と既存 Auto Tune v2 の接続

## 概要

人間がすべての粒界をなぞるのではなく、アルゴリズムの候補の一部をクリックで「正解」「誤検出」と判定する。未検出の粒界だけは2点で短い補完線を指定する。これらの判断は既存の Positive / Negative / Unknown 部分ラベルへ反映する。

**これは新規ニューラルネットワークのオンライン学習ではない。** 既存 Auto Tune のパラメータ最適化に、蓄積したラベルを利用する仕組みである。モデル・精度が必ず改善する保証はない。

## 操作

1. BMPを開き、粒界候補を「解析」する。
2. 上の「候補は正解」を押して、正しい抽出線をクリックする。
3. 「候補は誤検出」を押して、デンドライト等の誤認箇所をクリックする。
4. 検出漏れは「欠落を指定（2点）」で始点と終点を押す。これは画像 Evidence 探索ではなく**人間が指定した直線**であり、80プレビューpx以内かつ解析除外領域を横断しない場合だけ登録する。
5. 「評価結果を使って再調整（Auto Tune）」を押す。Development画像で、最低限のPositiveお手本が必要。
6. 比較・診断を確認し、必要に応じてUndo／再調整する。
7. 「保存」でプロジェクトJSONを書き出すか、IndexedDB自動保存を利用する。

中ボタンドラッグの一時パンは継続して使用できる。候補付近5px以内のピクセルを探索し、最も近い候補から12px半径・最大120画素の**連結した小領域**だけにPositive / Negativeを追加する。接続している結晶粒ネットワーク全体を一括承認しない。候補を選べないときは何も登録しない。

すでにラベル付けされた画素をクリックしても、内容に変更がなければ重複評価は作成しない。相反する参照中心線の同一箇所はクリアし、既存のUndo/Redoに1件の操作として登録する。

## 保存・互換性

- `reference.centerline`、`nonBoundary.centerline`：既存の部分ラベル資産（従来機能と共通）
- `feedbackReviews`：新規の軽量監査履歴（正解/誤検出/欠落、クリック座標、対象画素数、日時）。直近2000件を保存
- `diagnostic.json.feedbackReview`：判定件数と直近100件の監査情報
- Project Format v4を維持。過去のProject v1-v4は読み込み時に空の`feedbackReviews`を設定
- 新規ラベルは選択した画像指紋に紐づき、別BMPへ混同しない

## 学習・精度評価の注意点

- 未指定領域は **Unknown**。誤検出のクリックを周辺全域への完全評価として扱わない。
- 完全評価ROIの「検証完了」とは独立。人間がOK/NGを繰り返しても画像全体のTrue Precision / F1が自動的に算出されるわけではない。
- 明示されたValidation/Test画像では既存仕様どおりAuto Tune禁止。Test ROIもTune対象外。
- 既存Logistic Regression分類器はTraining ROIとValidation ROIを必要とする。この簡易フィードバックだけでClassifierを無条件に訓練・採用しない。
- 提示区間は密な交差部で他の枝を部分的に含む可能性があるため、結果を画面で確認して必要ならUndoする。
- 検出漏れを2点で結ぶだけでは、正しい曲線を復元できるとは限らない。曲がった線には短い区間を複数回指定する。

## テスト

`npm test` で Nodeの既存回帰テストと追加`tests/feedback-learning.test.js`を実行。

追加テスト: 過大な連結成分のラベル化防止、候補なし・除外領域の拒否、補完線距離と除外交差ガード、既存Project互換の保存・読み込み。

**未完了の実画像確認**: `269V2127_1S05C_center.bmp` と既存Projectを使用し、同じ評価領域で変更前後のPositive Recall、Negative Leakage、Verified ROI F1、Closure/Open@3を比較する。改善しない場合は従来パラメータに戻す。
